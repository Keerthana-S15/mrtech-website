# MRtech Ecommerce Website

## 📁 Project Structure
```
mrtech/
├── frontend/     (React App)
├── backend/      (Node.js + Express)
├── package.json  (Root)
└── .gitignore
```

## 🚀 Setup & Run

### 1. Install all dependencies
```bash
npm run install-all
```

### 2. Setup Backend .env
Create `backend/.env` file:
```
PORT=3000
ADMIN_EMAIL=your@gmail.com
ADMIN_PASS=your-app-password
```

### 3. Run Both (Frontend + Backend)
```bash
npm start
```

- Frontend: http://localhost:3001
- Backend: http://localhost:3000/api
